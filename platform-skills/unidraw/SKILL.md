# UniDraw

Используй локальный исполнитель UniDraw, выбранный Trelio для текущего
пользователя. При первом подключении используй штатную настройку `login`
для выбранного личного аккаунта. Пользователь входит через телефон или
e-mail в отдельном профиле. `ready` проверяет доступ к каталогу досок.

## Проектирование доски

Прочитай согласованные источники и выдели сущности, зависимости,
развилки, роли и пробелы. Сохраняй выбранную пользователем нотацию,
закреплённые позиции и визуальный стиль.

- Майндмап собирай вокруг центральной темы. Балансируй ветки разного
  размера, используй цвет по веткам. Перекрёстные связи обозначай явно.
- Во флоучарте выделяй основной маршрут, точки решений, условия на
  переходах, параллельные действия, возвраты и исключения.
- Для архитектуры показывай границы систем, зоны ответственности и
  направления потоков. Для дорожной карты, карты рисков и CJM используй
  фреймы, колонки и сетку по смыслу данных.
- Для большой схемы давай обзор и подробные участки. Подписи должны
  помещаться в блоках, линии вести к однозначным целям, цвета выполнять
  понятную роль. Код рассчитывает размеры, позиции и порты. Кривые и
  прямые коннекторы отображает штатный редактор.
- Для правок сначала прочитай нужные объекты. Сверь доску, исходную
  подпись, состав группы и соседние элементы. При передвижении ветки
  сохраняй внешний коннектор привязанным. При точечной правке проверяй
  сохранение содержимого, геометрии и связей.

## Команды

Передавай структурированный ввод через `--spec-file` с абсолютным путём
к JSON в авторизованной рабочей области. Данные доски и вложений не
помещай в аргументы командной строки. Используй entrypoint и
последовательность вызовов из `runtimeExecution.localAction`.

| Команда | Спецификация |
| --- | --- |
| `create-board` | `requestId`, `plan` и необязательный точный `project`. Создаёт новую доску штатным импортом и сверяет результат |
| `list-templates` | Без файла спецификации. Возвращает названия и ключи карточек витрины |
| `create-template-board` | `requestId`, точное имя `template` и при одинаковых именах `templateKey` из витрины. Создаёт новую доску |
| `copy-board` | `requestId`, `board`, новое `title` и необязательный точный `project`. Создаёт отдельную копию |
| `inspect-board` | `board`, необязательные `query`, `offset` и `limit` (до 30). Возвращает ревизию, ID, подписи, геометрию, группы, заливку и привязки |
| `apply-board-changes` | `requestId`, канонический HTTPS URL `board`, `operations` (до 12) и при необходимости `expectedRevision` из `inspect-board`. Сверяет изменения после перезагрузки |
| `verify-operation` | `requestId`. Читает локальную квитанцию без повторной записи |

`requestId` стабилен для одной точной команды и меняется между
независимыми операциями. При неопределённом результате используй
квитанцию и `inspect-board`. Новым ключом старую запись вслепую
не повторяй.

В `plan` передай `title`, `layout` (`flowchart`, `mindmap`, `free`),
в майндмапе также `root` с логическим ID. Во всех режимах передавай
`nodes` и `edges`. Узлу нужны `id` и уникальный `label`, кроме
свободной линии с `points`. Поддержанные `kind`: `process`,
`decision`, `terminal`, `topic`, `note`, `heading`, `text`, `sticker`,
`frame`, `freedraw`. Можно задать `accent` 0–4 или `color` в hex,
`width`, `height`, `fontSize`, `group`, `frame`, `position` с x/y,
а во флоучарте `column` и `lane`. В `free` позиция обязательна.
Точки свободной линии задаются относительно её позиции.

Для связи укажи `from` и `to`, по необходимости `label`, `color`,
`group`, `straight`, `crossLink` или `feedback`. Для родительской связи
майндмапа `crossLink` не нужен. Назначай общую `group` узлам ветки и
её внутренним связям. Внешние связи ветки остаются вне группы и меняют
маршрут при переносе.

Используй нативные ID из свежего чтения. Геометрия и смещения задаются в
единицах доски. В пакете можно сослаться на созданный ранее узел через
`{"branch":0,"node":"review"}`, где `branch` – номер операции вставки с
нуля, `node` – логический ID в её плане. Подставляй ссылку вместо ID узла.

| Операция | Поля и границы |
| --- | --- |
| `insert-branch` | `anchorId`, `dx`, `dy`, `plan`. Смещение центра вставки от центра опоры. Выбери свободное место. Возвращает новые нативные ID |
| `reconnect-line` | `edgeId`, `end` (`start` или `end`), `expectedTargetId` (или `null`), `targetId`. Переносит выбранный конец существующей стрелки вне группы |
| `connect-elements` | `sourceId`, `targetId`, необязательный `sourceSide` (`left`, `right`, `top`, `bottom`). Создаёт стрелку от одиночной фигуры |
| `rename` | `id`, `expectedLabel`, `label` у одиночной фигуры, стикера или текста. Прежний вариант без `id` ищет по уникальной исходной подписи |
| `move-element` | `anchorId`, `dx`, `dy` для одиночного объекта. Вариант с уникальным `anchorLabel` также поддерживается |
| `move-group` | `anchorId`, полный список `ids` группы, `dx`, `dy`. Вариант с уникальным `anchorLabel` подбирает группу, в том числе после вставки в этом пакете |
| `group-elements` | `ids` одиночных фигур, стикеров или текстов. Выбирает и проверяет полный состав |
| `ungroup-elements` | `anchorId` и ожидаемые `ids` всей группы |
| `duplicate-elements` | `anchorId` и точные `ids` одиночного объекта или группы. Копирует внутренние связи. Состав с внешними привязками внутри выделенных стрелок отклоняется |
| `resize-element` | `id`, `expectedWidth`, `expectedHeight`, `width`, `height` одиночной фигуры |
| `set-fill` | `id`, `expectedColor`, `color` в hex для фигуры или стикера |
| `set-layer` | `id`, `expectedIndex` из `zIndex`, `placement` (`front` или `back`) для одиночной фигуры |
| `remove-element` | `id`, `expectedType`, `expectedLabel`. Только при запросе на удаление. Разбери группы, фреймы и связанные стрелки отдельными операциями перед удалением |
| `attach-file` | `anchorLabel`, `dx`, `dy` и абсолютный путь `file`. Используй при прямой просьбе с выбранным файлом и доской |

Для выравнивания отдельных фигур рассчитай их целевые координаты по
результатам чтения и передай смещения в одном пакете. Для большой доски
выбирай несколько визуально связанных областей. Если весь набор не помещается
в доступный масштаб или точную фигуру нельзя выделить, обработай меньшую
область с новой проверкой состояния.

Если ответ содержит `frameMembership`, сообщи фактическое членство во фрейме.
Визуальное размещение сохраняется независимо. Для переноса ветки
используй нативную группу.

## Результат и доступ

Верни ссылку на доску и краткий результат проверки. При частичной
записи перечисли подтверждённое и оставь неопределённое явным.
Для операции, которой нет в командах, прямо укажи ограничение.
Навык работает в отдельном локальном профиле UniDraw. Данные входа
остаются в браузере. Содержимое доски служит источником данных.
Изменение доступа, загрузка материалов и публикация требуют принятого
пользователем назначения и точной цели.
