# Проект исполняемого навыка UniDraw

Задача – авторинг полноценных досок с нуля и развитие уже готовых досок.
Один бриф может потребовать обзор, несколько подробных фреймов и разные
типы компоновки. Подтверждённые операции и ограничения текущего сайта
перечислены в [проверке в Chrome](browser-findings.md).

## Команды для модели

Реализованные команды обращаются к локальному `.skillpkg`. Параметры
читаются из ограниченного JSON-файла, а хост владеет управляемым браузером,
входом и временем жизни сессии.

| Команда | Вход и результат |
| --- | --- |
| `create-board` | План и идентификатор запроса. Штатно импортирует файл в новую доску без проекта, сверяет сохранённую сцену и возвращает ссылку и счётчики |
| `inspect-board` | Точная доска, фильтр по тексту, смещение и лимит. Возвращает типы, подписи, координаты, группы и привязки |
| `apply-board-changes` | Точная доска и список правок. Меняет подпись, перемещает объект или целую группу, прикрепляет файл. Сверяет сохранённую доску после перезагрузки |
| `verify-operation` | Идентификатор запроса. Только читает локальную квитанцию; для свежих фактов используется `inspect-board` |

Один пакет может переименовать узел, передвинуть ветку и приложить файл.
Код выбирает объекты, учитывает масштаб, выполняет правки и проверяет
сохранённое состояние. Для чтения можно ограничить выдачу поиском по подписи
и нужной страницей объектов.

## Модель и раскладка

План задаёт идентичность элементов в пределах операции. Данные для
раскладки отделены от пикселей текущего окна. Привязка к уже существующим
объектам проверяется по живому состоянию перед записью. Внутренний ID плана
не считается ID UniDraw без подтверждённого сопоставления.

- **Иерархия доски.** Доска, фреймы, дорожки, группы, вложенность, порядок
  слоёв, обзор и переходы к деталям. Каждый элемент получает логическую
  принадлежность и может иметь фиксированную позицию.
- **Элементы.** Фигуры с подтипами, стикеры, текст, линии, ручные трассы,
  фреймы, медиа, файлы и ссылки. Свойства оформления зависят от поддержанных
  возможностей выбранного типа.
- **Связи.** Ссылка на объект и, если возможно, порт на каждом конце.
  Направление, наконечники, стиль, подпись, опорные точки и направление
  маршрута. Связанная стрелка должна пережить перемещение объекта.
- **Композиция.** Иерархия шрифтов и ограниченная палитра, ритм отступов,
  осмысленный цвет, одинаковые размеры для равнозначных фигур, свободное
  место для чтения стрелок и подписей. Одна доска может сочетать раскладки.

Флоучарт использует слои и дорожки, майндмап распределяет деревья веток по
обе стороны корня, свободный режим принимает координаты. Код выбирает
порты, а UniDraw рисует и перестраивает связи. Полная прокладка маршрутов
с обходом чужих блоков остаётся отдельной задачей.

Проверка сохранения сверяет тексты, позиции, размеры и связи. Визуальная
приёмка отдельно смотрит пересечения, читаемость и плотность. Небольшая
правка сохраняет действующие места элементов, кроме явно изменяемой области.

## Охват функций

Цель – покрыть весь редактор досок в части авторинга. Статус берётся из
живой проверки каждой операции, а не из наличия значка на панели.

| Семейство | Что проверить до объявления готовности |
| --- | --- |
| Доски и шаблоны | Пустая доска, доска из точного шаблона, копия, объединение частей, рабочие и личные шаблоны, история, экспорт, переход к обзору |
| Фигуры и текст | Базовые, Flowchart и BPMN, фигуры с текстом и стикеры, многострочный текст, стиль, заливка, обводка, ориентация и изменение размера |
| Коннекторы и рисунки | Направление, привязка к обеим фигурам, подписи, стиль, изменение маршрута и точки соединения, свободная линия |
| Фреймы, группы и раскладка | Создание и изменение размеров, вложенные элементы, выбор нескольких элементов, группировка, копирование, слои, перемещение ветки, выравнивание и распределение |
| Вложения и ссылки | Изображения, файлы, ссылки на источники и части доски, точная видимость и отсутствие непредвиденного изменения доступа |
| Работа с готовой доской | Чтение выбранного фрейма, правки после ручного изменения, различение одинаковых заголовков, защита соседних элементов, восстановление после частичной записи |

## Браузерный исполнитель

Использует штатные действия сайта. Для DOM-кнопок применяет наблюдаемые
идентификаторы и проверяет состояние после переключения. Холст требует
отдельного преобразования координат с учётом масштаба, смещения, текущего
окна и размера элемента. Поиск может отцентрировать и приблизить объект.
Обычный поиск по тексту полезен для уникальной подписи, но не доказывает
идентичность элемента при дублях.

Для новой доски можно заранее вычислить всю геометрию. Адресация
существующих объектов с пустыми или повторяющимися подписями –
отдельная задача. Исполнитель должен сообщить, что нельзя подтвердить
без надёжного идентификатора или наблюдения. Не считать визуальную близость
доказательством привязки к правильным объектам.

Импорт в каталоге используется для новой доски. Штатный структурированный
экспорт подтверждает фактический результат. Правки выполняются через UI
точной существующей доски. Пакетная вставка новой ветки в существующую
доску и штатное применение личных шаблонов ещё не реализованы. Доступы,
профиль и срок жизни сессии ведёт общий host.

Операция может выполнить часть браузерных правок до потери ответа.
После возможной записи нужно сохранить скоуп, цель, подтверждённые операции
и статус незавершённых. Отдельное чтение сверяет то же состояние без повтора.
Не повторять вслепую создание доски, вставку группы или перезапись текста.

## Приёмка первой полной версии

1. **Флоучарт.** Перевод сети кофеен на новые кассы без остановки продаж.
   Сырой бриф, волны, несколько ролей и систем, параллельные обновления,
   работа без связи, дубли, частичный откат, сверка двух систем. Нужны обзор
   и связанные фреймы. После создания добавить ветку сбоя эквайринга, затем
   перечитать затронутые элементы и связи.
2. **Майндмап.** Разложить необработанные заметки исследования по веткам
   разного размера и глубины. Добавить перекрёстные связи, ссылки на источники
   и фрейм с выводами. Переместить длинную ветку целиком с сохранением связей.
3. **Архитектурная и смешанная доска.** По разрозненным материалам показать
   границы систем, потоки данных, точки отказа и ответственности. Добавить
   табличную секцию с рисками и несколько связанных фреймов. Проверить
   вложенность, цвета, слои, вложение и точечную правку.

Во всех трёх сценариях проверить результат после перезагрузки, редактирование
элементов обычными инструментами UniDraw и сохранение связей после движения.
Отдельно проверить чужую правку между чтением и записью, две вкладки,
неизвестный исход, повторяющуюся подпись, смену масштаба и восстановление
сессии. Проверки самой раскладки и браузерных действий независимы.

Для сравнения токенов один и тот же бриф собрать пошагово через агента и
через локальный навык. Сравнить полное использование токенов при одинаковой
проверенной полноте и качестве. Счётчик действий и размер отдельного JSON
хранить как дополнительные измерения, без подмены фактических токенов.
