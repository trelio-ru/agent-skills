# Проверка редактора UniDraw в Chrome

Дата проверки – 21 ноября 2026 года. Использовалась уже авторизованная
сессия Chrome и отдельная доска, созданная из встроенного шаблона Flowchart.
Изменения вносились только в эту копию. Идентификаторы доски, аккаунт и
снимок браузера не входят в исходники навыка.

## Подтверждённые сценарии

| Сценарий | Как проверить | Наблюдаемый результат |
| --- | --- | --- |
| Создать доску из шаблона | В витрине «Создать доску из шаблона» нажать карточку Flowchart | Текущая вкладка переходит на новую доску с собственным URL и готовой схемой. Блоки и связи редактируются |
| Выбрать инструмент | Использовать `data-testid` кнопки в верхней панели | Инструменты находятся через DOM. На доске наблюдались `selection`, `hand`, `sticker`, `shape`, `line`, `frame`, `freedraw`, `text`, `fileUploader`, `comment` |
| Открыть полную библиотеку | Кнопка `shape` → «Все фигуры» | Наблюдались поиск по фигурам и категории «Базовые фигуры», «Блок-схема», «BPMN 2.0». В BPMN есть события, шлюзы, процессы, задачи, данные, маркеры, сообщения и стрелки |
| Найти и выбрать объект | Кнопка `elements-search-button` → активный combobox `element-search` → запрос `Start` → точный результат «Start Фигура» | Поиск вернул один объект с типом. Щелчок выбрал его на холсте и приблизил область. Поиск меняет масштаб и положение холста |
| Переместить связанную фигуру | Выбрать найденный блок и перетащить за тело фигуры | Фигура сместилась, штатная стрелка изменила наклон и осталась соединена с обеими фигурами |
| Отредактировать подпись | Двойной щелчок по фигуре открыл один видимый `contenteditable`. Ввести «Приём заявки» и выйти из редактирования клавишей Escape | Подпись обновилась. После перезагрузки точное совпадение находилось через поиск, а на холсте остались новая позиция и соединённая стрелка |
| Выбрать несколько объектов | Включить `selection`, перевести фокус на холст и нажать Cmd+A | Панель показала «14 объектов» на копии Flowchart |
| Найти команды холста | Открыть контекстное меню на выделенных объектах | Видны «Скопировать», «Скопировать как PNG», «Скопировать как SVG», «Скопировать стили», «Скопировать ссылку на это место», «Сгруппировать». Выполнение каждой команды предстоит проверить отдельно |

Страница содержит полноразмерные `canvas`. Просмотр обычного DOM не даёт
полного списка фигур, геометрии и связей. Зато временный редактор подписи
доступен как обычный DOM-элемент, а результаты поиска содержат текст и тип.
После холодной загрузки надо дождаться готовности редактора и проверить, что
панель действительно открыта. В первой попытке ранний щелчок по кнопке
поиска после перезагрузки не открыл поле. Последующий щелчок после чтения
текущего состояния открыл поиск. После возможной записи проверяется
состояние доски, автоматического повтора записи нет.

## Другие доступные точки входа

- Витрина включает Flowchart, два варианта «Интеллект-карта», C4 Model,
  BPMN 2.0, карту рисков, дорожную карту, CJM, Event storming и другие макеты.
  Заголовок шаблона сам по себе не гарантирует уникальность.
- Меню `menu-button` содержит «Создать копию», «Сохранить в личные
  шаблоны», «Сохранить файл», «Открыть файл», «Сохранить версию» и
  «История версий». Это наблюдение меню, а не доказательство результата
  каждой операции.
- Мини-карта и масштаб имеют DOM-кнопки `minimap-button`,
  `elements-zoom-out-button`, `elements-rezet-zoom-button` (так написан
  идентификатор на сайте), `elements-zoom-in-button`. Подменю
  «Масштабирование» показывает режимы управления колесом мыши.
- В присланных пользователем диалогах на главной видны импорт файла доски
  `.unidraw` и импорт BPMN 2.0 `.bpmn` / `.xml`. В меню открытой доски
  «Открыть файл» перечисляет BPMN 2.0 `.xml` и Miro. Это разные точки
  входа. Поведение импорта на непустой доске и пригодность для записи
  отдельных правок не проверены.

Поддерживаемый внешний API для объектов доски на момент проверки не найден.
Проверка проводилась пользовательскими действиями и чтением публичных
элементов интерфейса. Внутренние HTTP/WebSocket-протоколы не исследовались.

## Прогон исполнителя на новых досках

21 ноября 2026 года в Chrome с уже авторизованным аккаунтом были открыты
отдельные вкладки и созданы новые QA-доски. Запускались исходные
`compileBoard`, `importBackups`, `exportBoard`, `verifyImport`,
`renameFigure` и `moveGroup` с адаптером Chrome. Новый личный профиль
подписанного пакета не проверялся в этом прогоне.

| Сценарий | Результат |
| --- | --- |
| Миграция кассовой платформы | 21 фигура и 21 связь. Подпись «Классифицировать сбой» стала «Определить тип сбоя». Нативная группа ветки офлайн-очереди сместила 3 фигуры на 69 единиц при запрошенных 70. После перезагрузки сохранены все привязки |
| Исследование потерь заказов | 23 фигуры и 24 связи. Заголовок корня изменился. Четыре фигуры ветки «Работа точки» сместились на 90 единиц. После перезагрузки сохранены все привязки |
| Нативные элементы | Созданы фрейм, текст, стикер, свободная линия, фигуры и стрелки из локального плана. Через штатную загрузку появились изображение и файлы. Стикер отдельно переименован, одна фигура передвинута без группы |

### Точные методы и ограничения

- Каталог «Импортировать» → «Файл доски» → выбор `.unidraw` →
  «Импортировать». При успехе модалка показывает результат каждого файла.
  Новые доски появляются в «Мои доски» даже раньше, чем в «Недавнее».
- Меню доски «Сохранить файл» → «Файл доски» → «Сохранить бэкап на компьютер»
  отдаёт JSON `type: unidraw`, `version: 1`. `tipPoints.start/end.boundToId`
  дают концы линии, `captions` – её подписи, `groupIds` – состав
  группы. Экспорт используется для проверки. В Chrome тестовый адаптер
  прочитал только новый файл с точным названием своей QA-доски.
- Точный поиск центрирует область фигуры и меняет масштаб. Контекстное
  меню даёт «Разгруппировать» и счётчик группы. Расстояние переводится
  в пиксели после измерения масштаба. После Escape нужно дождаться
  закрытия меню. У одиночной фигуры щелчок может открыть редактирование
  текста, и Escape сначала закрывает именно редактор.
- Фрейм и потомки визуально сохраняют позиции. В проверенном импорте
  экспорт вернул пустой `frame.children` вместо шести связей. Текст
  измерен заново, ширина стикера приведена к собственному соотношению
  сторон. Исполнитель отдельно возвращает результат членства во фрейме.
- `fileUploader` открывает выбор файла. После выбора одно нажатие на
  холст размещает элемент. Экспорт возвращает имя, размер и
  `status: saved` для файла; для изображения также запись в `files`.
- Скопированная нативная группа представлена обычным текстом и HTML с
  маркером `data-unidraw`. Прогон 0.2.0 ниже подтвердил формат и вставку.

### Оставшиеся проверки

- Проверить объекты без подписи, вложенные группы и изменение доски в другой
  вкладке между чтением и записью.
- Проверить личные шаблоны, выбор именованного проекта и полную библиотеку
  специализированных фигур, включая BPMN. В меню тестового аккаунта был
  доступен вариант «Без проекта».
- Запустить подписанный пакет через управляемый профиль Trelio. Подтвердить
  вход, восстановление сессии и получение файла экспорта через Playwright.

## Прогон 0.2.0

- На свежей копии сложного флоучарта пакет добавил 3 узла и 2 связи,
  перенаправил существующую стрелку на первый добавленный узел и сместил
  всю новую группу. После перезагрузки экспорт содержал 24 фигуры, 23 связи,
  все 5 членов группы и её входящую привязку. Отдельно подтверждён перенос
  по списку нативных ID.
- На исследовательской копии подтверждены вставка, перепривязка изогнутой
  стрелки, добавление новой, смена заливки, изменение размера, передний план,
  правка одной из одинаковых подписей, группировка, разгруппировка,
  дублирование группы и удаление одной синтетической стрелки.
- В каталоге провели выбор одного из двух одноимённых майндмапов по отпечатку
  картинки. После перезагрузки на новой доске сохранены 80 объектов.
  Карта рисков сохранила 133 объекта. Штатная копия флоучарта сохранила 47.
- Штатная ссылка объекта содержит `elementId`. Она центрирует камеру,
  но требует отдельно выбрать объект. Для одиночного объекта копирование
  ссылки подтверждает точный ID. Для группы Copy переназначает ID и позиции
  слоёв, поэтому состав проверяется по уникальной геометрии, типам и подписям.
- Буфер вставки использует UTF-8 JSON типа `unidraw/clipboard` в HTML
  `data-unidraw`, оболочку `unidraw-data-v1` и Base64 со сдвигом байта
  на 59. Браузер переназначает ID, сохраняет нативную группу и относительное
  расположение и центрирует вставку у курсора. Вставленный фрейм снова
  сохранился визуально с пустым `children`.
- При перемещении связанной ветки экспорт после перезагрузки может вернуть
  устаревший кэш абсолютной координаты одного конца. Проверяются нативные
  ID фигур и стрелки, положение фигур, относительный порт, связь и оформление.
  Для стикеров с авторазмером шрифта сохраняется настройка авторазмера.
- Пользовательский Chrome использовался через отдельный адаптер. Методы
  Playwright для HTML Paste и перехвата Copy проверены отдельно в headless
  Chromium на синтетической странице, без системного буфера.

## Проверка подписанного выпуска 1.0.0

24 ноября 2026 года отдельно подтвердились первый вход, восстановление
сессии при новом запуске и чтение витрины. Два чтения существующей доски
завершились общей ошибкой до записи. Создание из Flowchart завершилось
неизвестным исходом в квитанции, без адреса сохранённой доски. Клик не
повторяли. В обычном Chrome меню экспорта, формат и кнопка скачивания
были доступны для этой тестовой доски.

В 1.0.1 команды редактора используют штатный фоновый Chrome с полноценным
окном и прежним локальным аккаунтом. Экспорт сообщает, на каком шаге
остановился. Шаблон проверяет доступность клика до создания квитанции.
Если после возможной записи браузер увидел новый адрес, квитанция сохраняет
его до ожидания редактора. Проверка после перезагрузки остаётся обязательной.
