# Проверка российского юрлица

Для запуска используй точный `runtimeExecution.localAction` из `get_agent_skill` и передавай команды через `parameters.arguments`. Достаточно десятизначного ИНН юрлица. Пакет проверяет контрольную цифру. Браузер работает в гостевом профиле Трелио. ФНС запускается без окна, КАД и Федресурс – в видимом Chromium. Эти режимы закреплены в пакете.

По умолчанию обработай все три источника последовательно. Если пользователь перечислил источники, проверь только их. Для каждого передай `check <реестр> <ИНН>`. Реестры обозначаются `fns`, `kad` и `fedresurs`. При `pending` выполни возвращённый `resume` для того же источника и ИНН. При `closing` повтори указанную команду после паузы в одну секунду. Переходи к следующему источнику только после закрытия предыдущего. `doctor` проверяет наличие нужных API хоста без запуска Chromium и запросов к реестрам.

## Если изменился интерфейс

При `visual_review` используй штатный визуальный режим в той же сессии. Перепроверь текущую форму или выдачу через `read-text <реестр> <ИНН>` и `screenshot <реестр> <ИНН>`. Сохраняй исходный ИНН и каждый раз используй свежий `frameId`. Отдельное согласование для перехода к визуальному режиму не требуется.

- `click <реестр> <ИНН> <frameId> <x> <y>` – координаты видимого элемента формы в текущем кадре.
- `scroll <реестр> <ИНН> <frameId> <x> <y> <deltaY>` – прокрутка текущей страницы.
- `enter-inn <реестр> <ИНН> <frameId>` – ввести исходный ИНН в поле, которое только что выбрано по кадру.
- `key <реестр> <ИНН> <frameId> <клавиша>` – очистить поле, переместить фокус или отправить точный поисковый запрос.
- `close <реестр> <ИНН>` – закрыть браузер после визуальной проверки или при подтверждённой недоступности.

Сначала выясни по странице, был ли принят прежний запрос. Если это неизвестно, перечитай текущую выдачу. Повторно отправляй запрос только после подтверждения, что поиск ещё не начался. При HTTP-отказе, CAPTCHA, запросе авторизации или потере браузера укажи, что источник недоступен. Оставшиеся источники проверь в рамках поручения. Для действий на сайте используй только публичную форму поиска этого реестра.

## Как оформить результат

По каждому источнику дай итог, ссылку на реестр и дату проверки. ФНС – название, ИНН и ОГРН из совпавшей карточки. КАД – до четырёх номеров дел из поиска по ИНН участника. Федресурс – совпадение в реестре должников, ОГРН и стадия, дата или номер дела, если эти сведения показаны. При визуальной проверке сверь ИНН в поле поиска и в карточке, если идентификатор там опубликован. Для КАД достаточно подтвердить поле участника и обновление выдачи.

Используй «совпадений нет» только при явном ответе поисковой формы по этому ИНН. При неясной выдаче укажи, какие данные удалось проверить. Для Федресурса вывод относится к поиску по реестру должников. Для КАД найденные дела показывают участие организации и сами по себе не определяют её роль или наличие долга.
