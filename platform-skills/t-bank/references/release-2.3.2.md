# Т‑Банк 2.3.2

Runtime 1.3.2 перед системным разблокированием читает название текущего чата
по `CODEX_THREAD_ID` из локального Codex App Server и сверяет ID ответа.
Точное название имеет приоритет над переданной агентом темой. Если локальное
чтение недоступно, прежний optional `requestTitle` остаётся запасным вариантом;
при отсутствии обоих значений системное окно показывает нейтральный текст.

Заголовок не сохраняется в vault или lease. Native macOS/Windows helper и его
trusted-app identity не меняются.
