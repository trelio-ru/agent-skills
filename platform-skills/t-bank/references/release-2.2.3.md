# Т‑Банк 2.2.3

## Что исправлено

Runtime 1.2.3 продолжает делегированный T‑ID вход, когда первый экран Т‑БКИ
показывает только поле телефона и безымянную кнопку-стрелку. После ввода private
adapter повторно сверяет канонические цифры в exact bound input и отправляет
Enter из этого поля.

Runtime не выбирает безымянную кнопку по позиции, поэтому не может перепутать
submit со встроенной кнопкой очистки. Несовпадение номера по-прежнему
завершается `auth_phone_input_mismatch` без повторного ввода или submit.

## Миграции и env

Повторный setup, перенос vault, DB migration и новые env не нужны. Minimum host –
1.6.17. Версия skill – 2.2.3, runtime – 1.2.3.

## Проверка после публикации

По прямому запросу владельца этот аварийный patch выпущен без автоматических
regression-прогонов. Tagged workflow только собирает immutable package.

Остановить незавершённый authorizer 2.2.2, начать новую авторизацию через
current 2.2.3 и один раз пройти реальный Т‑БКИ flow. Старую transaction нельзя
возобновлять новым helper-ом.

## Rollback

Остановить незавершённый authorizer и выпустить новый immutable runtime. Не
переносить tag, не стирать encrypted vault и не повторять login submit после
неизвестного результата.
