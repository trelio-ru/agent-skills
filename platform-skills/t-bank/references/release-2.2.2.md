# Т‑Банк 2.2.2

## Что исправлено

Runtime 1.2.2 больше не дублирует код страны при вводе российского телефона в
управляемую маску T‑ID. Сохранённые формы `+7…`, `7…`, `8…` и десять
национальных цифр приводятся к одному десятизначному вводу; видимый `+7`
остаётся состоянием provider-а.

Перед нажатием «Далее» private adapter сверяет канонические цифры внутри exact
bound input. Значение не возвращается через CLI/MCP или диагностику. Сдвиг,
обрезание и неподдерживаемый формат завершаются fail-closed без submit,
повторного ввода и ложного перехода к ручному challenge.

## Миграции и env

Повторный setup, перенос vault, DB migration и новые env не нужны. Minimum host –
1.6.17. Версия skill – 2.2.2, runtime – 1.2.2.

## Что проверить после публикации

Каталог должен вернуть 2.2.2/runtime 1.2.2 и новый exact package digest.
Единственный cross-platform PR gate проверяет маску T‑ID и полный synthetic
делегированный flow на macOS и Windows. Tag переиспользует зелёный exact SHA и
только собирает release artifact.

## Rollback

Остановить незавершённый authorizer и выпустить новый immutable runtime. Не
переносить tag, не стирать encrypted vault и не повторять login submit после
неизвестного результата.
