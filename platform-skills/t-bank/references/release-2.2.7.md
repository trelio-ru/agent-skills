# Т‑Банк 2.2.7

## Что исправлено

Runtime 1.2.7 больше не оставляет завершившийся вход в `authenticating`, когда
в доказанном кабинете `/mybank/` присутствует один обычный видимый input поиска
или продуктового виджета. Широкий locator по-прежнему распознаёт нестандартные
ячейки T‑ID на auth origin, но не подменяет классификацию challenge в кабинете.

Готовность по-прежнему требует официальный `/mybank/`, отсутствие password,
username и классифицированного auth challenge, признак раздела счетов, а также
видимый logout либо две точные ссылки «Операции» и «Кэшбэк и бонусы» внутри
официальной области кабинета. Один URL готовность не доказывает.

## Миграции и env

Повторный setup, перенос vault, DB migration и новые env не нужны. Minimum host
остаётся 1.6.17. Версия skill – 2.2.7, runtime – 1.2.7.

## Проверка после публикации

На macOS и Windows обязательны детерминированный package check и полный
T‑Bank security gate exact source SHA. После guarded publication нужен один
реальный вход с уже настроенным vault: `authenticating` должен перейти в
`ready`, а минимальный read-only script – получить исходные `context` и `page`.

## Rollback

Остановить незавершённую сессию и выпустить новый immutable runtime. Не
переносить tag, не стирать encrypted vault и не повторять login/TOTP submit
после неизвестного результата.
