# Проверка на macOS, 9 сентября 2026

Проверка выполнена по прямому разрешению владельца на отдельной development
identity, без переноса сессий других навыков. Содержимое переписок, идентификаторы
собеседников, QR-код и credentials в этот отчёт не входят.

- Локальное QR-окно открылось; сканирование владельцем перевело session в `ready`.
- `dialogs limit=100` вернул 100 чатов, `hasMore=true`, `complete=false`.
- `read limit=3` вернул три сообщения с нормализованными полями и курсором.
- Локальный `search` и поиск `contacts` вернули по три результата с partial coverage.
- `unread` вернул один чат. Снимки unread counters до и после серии чтений совпали.
- Policy осталась `confirm`, company autonomous flag – `false`.
- Explicit `stop` и отдельный `status` подтвердили `closed`.
- Новый `start` восстановил `ready` из encrypted storage без нового QR-входа
  и без системного подтверждения. После проверки снова подтверждён `closed`.

Реальная отправка, редактирование, удаление и изменение групп не выполнялись:
для них не было exact разрешения на конкретный чат и payload. Их guards и
сценарий ambiguous/no-retry проверены синтетически. Отчёт не доказывает delivery.

Native synthetic tests отдельно проверяют создание/повторное чтение/удаление
тестового Keychain key без UI и принудительное завершение зависшего worker.
Windows не проверялась на настоящей OS и не допускается публичным entrypoint v1.
