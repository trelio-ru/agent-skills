# Общие provider навыки

У каждого provider собственные `SKILL.md`, runtime source, references и tests.
Исполняемые пакеты описывает `release.json`; декларативные Remote MCP providers –
`remote-mcp.json`. Instruction-only навыки не создают фиктивный `.skillpkg`.

Граница репозиториев и проверок – в [README](../README.md).
Публикация и отдельная Telegram-сборка – в [release-process](../docs/release-process.md).
