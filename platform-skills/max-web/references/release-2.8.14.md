# max-web 2.8.14

MAX может вернуть cold deep link нового контакта на главную. Runtime сохраняет
проверенный официальный phone-lookup locator в личном owner-only журнале,
повторяет поиск в том же guarded profile и сверяет прежний exact URL.
Пустой HTML-атрибут contenteditable распознаётся как доступный composer.
Смена адресата или отсутствие готовой поверхности чата блокирует сообщение.
Журнал не выдаёт номер через knownChats; новый login сбрасывает locator.

Проверки: холодный переход после phone lookup, сменившийся номер, неизвестная
ссылка, поздняя смена маршрута, private namespace и сохранение unread-state.
Минимальная версия host остаётся 3.4.0.
