# max-web 2.8.18

Чтение личного диалога распознаёт штатную карточку «Сообщений пока нет» /
«No messages yet» в единственной видимой history. После bounded гидратации
runtime проверяет прежний exact маршрут, профиль, composer, отсутствие loader
и структурных сообщений. Возвращается `messages: []`,
`emptyState=direct-chat-empty`; ручной осмотр для этого состояния не требуется.
Номер, сохранённый locator и composer сами по себе не доказывают пустоту.
Полученный результат описывает текущую историю, а не отсутствие переписки
когда-либо. Появившиеся при загрузке сообщения имеют приоритет.

Неизвестная разметка остаётся `MAX_UI_UNSUPPORTED`, смена чата –
`MAX_CHAT_IDENTITY_UNVERIFIED`. Диагностика содержит только структурные
признаки, без текста, номера, названия, DOM или screenshot. Passive-read guard
и согласование отправки сохраняются; первая реплика опирается на указания
оператора и контекст обращения.

Проверки: пустой диалог после официального phone lookup и cold deep link,
bounded поздняя загрузка сообщений, composer-only shell, loader, чужая/скрытая
карточка, blocked/group/Favorites surface, неизвестные message nodes и смена
маршрута. MAX regression на Linux/macOS/Windows. Minimum host остаётся 3.4.0.
