# max-web 2.8.17

Остановка ручного режима сначала передаёт полный ответ, затем закрывает
локальный управляющий HTTP-канал. Незавершённые соединения и keep-alive
не задерживают закрытие браузера до HTTP timeout. При отключении вызывающего
клиента cleanup продолжается. Новые действия после принятой остановки запрещены.

Подтверждение закрытия по exact terminal receipt, passive-read guard,
абсолютный срок и проверки ожидающих file transfers сохраняются.

Проверки: реальный TCP-клиент с незавершёнными headers, полная доставка
stop acknowledgement и cleanup при разрыве соединения; MAX regression на
Linux/macOS/Windows. Minimum host остаётся 3.4.0.
