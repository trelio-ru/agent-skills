# max-web 2.8.20

Пустой личный чат распознаётся и в текущей вложенной разметке MAX:
`openedChat > .history` окружает внутреннюю `.history` с карточкой
«Сообщений пока нет» и composer. Runtime выбирает единственную видимую
внутреннюю историю; независимые истории и загрузка внешней оболочки
по-прежнему блокируют вывод о пустоте. Exact маршрут, профиль, отсутствие
сообщений и полное bounded ожидание остаются обязательными.

Сохраняется исправление read-only phone lookup из 2.8.19: ручной режим
открывает новый контакт через штатную точную кнопку «Найти по номеру».
Подготовка с неизвестным UI сохраняет безопасную причину, без generic worker
failure и без дополнительных прав на отправку.

Проверки: вложенная история, отдельные конкурирующие истории, busy ancestor
и внешний loader; MAX regression на Linux/macOS/Windows.
Minimum host остаётся 3.4.0.
