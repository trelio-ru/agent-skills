# max-web 2.8.11

Неоднозначное имя возвращает `MAX_CHAT_AMBIGUOUS` с кандидатами и готовым
read-only recovery. Assist сохраняет поиск при неоднозначной подготовке,
чтобы агент мог сам осмотреть тёзок без трёх одинаковых попыток.

Успешное чтение и снимок открытого чата возвращают проверенные URL и ID.
Личный bounded журнал сохраняет их между обращениями отдельно от live выдачи.
Optional task ref закрепляет выбранную переписку только после exact чтения;
появление одноимённого чата не заменяет прежнюю ссылку. Отправка сохраняет
обычное согласование exact получателя, без автоматического task binding.

Проверки: MAX runtime regressions на Linux/macOS/Windows; отдельные сценарии
тёзок, task-scoped reuse, запрета mutation binding, повреждённого журнала,
symlink и ограничения размера. Минимальная версия host остаётся 3.4.0.
