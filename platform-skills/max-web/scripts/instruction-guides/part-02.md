- `dialogs`, `contacts`, `profile`, `read`, `unread`, bounded `watch`, `download` и любые
  действия до проверенного ответа сохраняют server-side unread-state. Runtime
  блокирует `READ_MESSAGE` и `READ_REACTION`; не компенсируй чтение поздней
  пометкой «непрочитано».
- Read receipt разрешается только после успешно проверенного `send` или
  `reply`. Ошибка или неоднозначный результат не отмечают входящие прочитанными.
- Partial match допустим только для discovery. Перед действием должен
  разрешиться один exact нормализованный чат; неоднозначность fail-closed.
- Личное `Избранное` имеет официальный маршрут `https://web.max.ru/0`.
  Runtime принимает и exact название, и `/0`, а при нормализации SPA к `/`
  открывает зарезервированную строку с `listIndex=0` в папке «Все» и проверяет
  маршрут `/0`, выбранную строку и заголовок `Сообщения для себя`. Не ищи
  `Избранное` глобальным поиском: там встречаются одноимённые публичные каналы.
- `read` возвращает bounded history с provider message ID, автором, временем,
  направлением, reply context и метаданными вложений, когда MAX однозначно
  показывает поля.
- `Сохраните что-нибудь` – служебная карточка внутри любого личного
  `Избранного`, а не признак пустой истории и не сообщение. Runtime ждёт bounded
  гидратацию exact `/0` surface; только отсутствие обычных message wrapper после
  этого окна вместе с видимыми composer и служебной карточкой означает
  `messages: []`, `emptyState=favorites-empty`. При неизвестном состоянии ошибка
  содержит только безопасные структурные признаки маршрута, строки, заголовка,
  composer и числа wrapper – без текста чата, DOM или screenshot.
- В обычном личном диалоге runtime распознаёт штатную карточку
  `Сообщений пока нет` / `No messages yet` внутри единственной видимой истории.
  Вложенный контейнер истории внутри оболочки `openedChat` считается одной
  историей; независимые видимые истории остаются неоднозначными. Загрузка
  во внешней оболочке также блокирует вывод о пустоте.
  После bounded ожидания загрузки, при прежнем exact URL, заголовке профиля,
  доступном composer и отсутствии сообщений и загрузчика `read` возвращает
  `messages: []`, `emptyState=direct-chat-empty`. Это нормальное отсутствие
  текущей переписки, включая нового контакта по телефону; ручной осмотр не нужен.
  Один найденный номер, composer или ноль распознанных сообщений пустоту не
  подтверждают. При неизвестной разметке сохраняется `MAX_UI_UNSUPPORTED`.
