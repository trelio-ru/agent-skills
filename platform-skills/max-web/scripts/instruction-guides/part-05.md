Перед ручной mutation проверь живое состояние exact чата и результат действия
в том же профиле. Если нужный результат уже есть, остановись. Для `member-add`
после неоднозначного ответа сначала используй `members` либо ручную session
`--fallback-for members` только для проверки состава. Если отсутствие бота
подтверждено, заверши эту session и открой отдельную exact session для
`member-add` с обычным подтверждением. Для другой mutation так же проверь её
точный результат; если он неясен, используй ручную session только для осмотра.
Не выполняй изменение, пока состояние не установлено. Это правило разрешает
ручной путь после трёх локальных сбоев, в том числе timeout UI или
`MAX_PICKER_TARGET_UNRESOLVED`, но не объявляет timeout доказательством
отсутствия эффекта.
Если даже вручную MAX не предлагает exact бота или отклоняет добавление,
проверь доступный статус и сообщи владельцу бота о настройке разрешения
добавлять его в групповые чаты; по умолчанию она выключена. Не объявляй
ограничение навыка доказанным запретом MAX.
