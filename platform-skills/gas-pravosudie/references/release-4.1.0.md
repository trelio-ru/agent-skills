# 4.1.0

Перед любой судебной подачей навык проверяет раздельность самостоятельных
документов, понятные русские названия транслитом и фактическое количество листов
в имени каждого PDF. Правило действует для нового обращения, существующего
дела, копий участникам и исправленного комплекта после отклонения.

Подготовка и подсчёт страниц выполняются до подписи. Изменение байтов PDF
требует новой подписи; простое переименование допускает прежнюю подпись только
при точном совпадении SHA-256. После загрузки сверяются файлы и видимые названия
в форме ГАС. Непроверенное содержимое или количество страниц блокируют подачу.

Транслит — рабочее правило навыка; требование суда состоит в идентификации
документа и количества листов. Подготовка не разрешает повторную отправку.

Runtime 1.0.5 и minimum host 2.4.0 сохранены: executable package не меняется,
новое правило доставляется основными инструкциями навыка. Проверки включают
регрессии инструкции и синтетические forward-сценарии без внешних действий.
