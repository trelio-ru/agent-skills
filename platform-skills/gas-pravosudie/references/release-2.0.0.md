# ГАС «Правосудие» 2.0.0

## Что вошло в релиз

Процедура ГАС использует отдельный secure-browser для сайта и обращается к
Госуслугам только за ЕСИА-авторизацией. Требуется разрешение пользователя на
вход в ГАС; ранее данное в текущем разговоре не спрашивается повторно.
После входа этот навык проверяет кабинет и продолжает в том же браузере.

## Миграции и env

Instruction-only release без runtime package, env и DB migration. Требуются
назначенные secure-browser 1.0.0+ и Госуслуги 3.0.0+. Сохранённый доступ ЕСИА
не меняется и не требует повторного setup.

## Что проверить после деплоя

Каталог возвращает инструкцию 2.0.0. Агент открывает ГАС через secure-browser,
проверяет разрешение, вызывает Госуслуги authorize по фактическому request,
потом читает кабинет через прежний browser session ID. Подготовка документов
и проверка статусов остаются в ГАС; согласие/подпись/подача отдельны.

## Rollback

Остановить процедуру на текущем безопасном шаге и исправить инструкцию новой
версией. Не возвращать внешние страницы в runtime Госуслуг и не переносить
сохранённые credentials/cookies между навыками.
