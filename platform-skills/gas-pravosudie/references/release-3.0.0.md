# ГАС «Правосудие» 3.0.0

## Что вошло в релиз

Процедура работает в обычном Playwright context и использует клиент Госуслуг
только для ЕСИА. После входа сохраняются исходные context/page; формы,
загрузка документов и скачивание выполняются обычным кодом сценария.
Зависимость от отдельного secure-browser удалена.

## Миграции и env

Instruction-only release без runtime package, env и DB migration. Требуются
назначенные Госуслуги 4.0.1+. Сохранённые доступы ЕСИА не меняются.

## Что проверить после деплоя

Каталог возвращает инструкцию 3.0.0. Агент получает verified `client`, подключает
помощник перед штатным входом и проверяет кабинет в той же вкладке. Полный
context не даёт разрешения на подачу, согласие или подпись. Auth DOM, cookies
и сетевые тела не выводятся модели. Сценарий закрывает свой браузер в `finally`.

## Rollback

Остановить процедуру на безопасном шаге и исправить инструкцию новой версией.
Не переносить credentials между навыками и не восстанавливать автоматически
удалённую зависимость исторической инструкции.
