# 4.1.1

Минорная ветка 4.1 проверяет подготовку любого судебного комплекта: отдельные
документы, русские названия транслитом и фактическое количество листов в имени
PDF. Проверка выполняется до подписи и повторяется для загруженного комплекта
и видимых наименований в форме ГАС.

Runtime 1.0.6 получает отдельную immutable identity для этой публикации.
Минимальный host 2.4.0 и логика browser runtime сохранены. Исправления PDF
требуют новой подписи; подготовка не разрешает повторную подачу.

Проверки: синтетические forward-сценарии, instruction regressions с LF/CRLF,
общий package gate и runtime regressions на Linux, macOS и Windows.
