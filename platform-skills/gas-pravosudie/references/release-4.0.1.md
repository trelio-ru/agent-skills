# ГАС «Правосудие» 4.0.1

## Исправление входа

Фоновый headed browser может получить компактную ширину. Live-сайт
`ej.sudrf.ru` в таком окне скрывает ссылку «Вход» в Bootstrap-меню, поэтому
release 4.0.0 ошибочно завершал `prepare-sign-in` с
`court_login_entry_unavailable`, хотя точная ссылка уже была в DOM.

Runtime 1.0.1 раскрывает только один видимый штатный переключатель
`button.navbar-toggle` с подписью «Показать меню», повторно проверяет
единственную ссылку `a[title="Вход"]` и нажимает её в фоне. Вкладка не
активируется, скрытая POST-форма напрямую не отправляется, а все прежние
проверки exact соглашения и делегированного ЕСИА helper сохраняются.

## Проверка

Кроме deterministic unit/package checks релиз проверяется live smoke на
публичном `https://ej.sudrf.ru/`: исходная ссылка действительно скрыта при
компактной ширине, меню раскрывается, форма соглашения распознаётся и реальный
ЕСИА request передаётся текущему verified runtime Госуслуг до auth boundary.
