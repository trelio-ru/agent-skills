# ГАС «Правосудие» 4.1.10

Перед судебной подачей агент проверяет применимые требования и подтверждения,
а затем сверяет их с окончательными файлами и фактически загруженными
приложениями. Проверка нужна при подготовке нового обращения, подаче в
существующее дело и устранении недостатков.

- Рабочая таблица связывает требование, подтверждаемый факт, точную исходную
  страницу, окончательный PDF и состояние проверки. Неприменимость требует
  причины, существенный пробел останавливает подготовку к подаче.
- Если основание выбора суда связано с местом жительства или пребывания,
  проверяется подтверждение адреса. Для паспорта нужна читаемая страница со
  штампом регистрации; разворот с фотографией её не заменяет. Требование
  не распространяется автоматически на любую подачу.
- Недостающие подтверждения сначала ищутся в разрешённых сохранённых
  материалах. Скан без OCR проверяется по изображению; расхождение адресов,
  нечитаемая страница и недоступный источник остаются явными пробелами.
- Изменение PDF сохраняет обязательную новую подпись. Проверка не даёт
  отдельного разрешения на отправку и не заменяет юридическую оценку runtime-ом.

## Граница проверки релиза

Последний опубликованный baseline — `skill-gas-pravosudie-v4.1.8`, source
`7f611c130f4a37d0988a3b3344d83bf750d06468`. Сравнение с этим baseline также
включает ранее интегрированный переход на независимые сессии чатов из source
`601931ed47a3cfa9a4eeeadf2c5e9c00ba5603e2` и публичные требования подключения.
Эти изменения нельзя считать частью одного текстового исправления без проверки:
provider gate сохраняет native macOS/Windows и общий session/CAS contract с
закреплённым host source `c0cf6b81624560c7cbedacf57077b4cbfcddc6a7`.
Backend/host ABI этой правкой не меняется; minimum host остаётся `3.31.0`.

Runtime получает отдельную новую версию `1.0.15`. Проверяются доставка полного
обязательного корпуса в подписанном package, таблица подтверждений и
синтетические forward-сценарии, включая пропущенную страницу регистрации.
Эти проверки не являются гарантией поведения модели на живой судебной подаче.
