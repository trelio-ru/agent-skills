# 4.1.6

## Что вошло в релиз

Проверка движения поданного иска или дела охватывает личный кабинет ГАС и
публичную картотеку соответствующего суда. Если номер неизвестен, агент ищет
по фамилии, сверяет стороны и дату поступления и читает движение в карточке.
Прямая ссылка и точный вид номера сохраняются для следующих проверок.

Пустая выдача и статус регистрации не доказывают отсутствия производства или
судебного акта. Недоступный источник остаётся явным пробелом; узкое поручение
проверить только обращение или карточку сохраняет свою область. Проверка не
разрешает новые подачи, звонки и письма в суд.

## Миграции и env

Runtime 1.0.11 имеет новую immutable version для изменённого signed package.
Minimum host остаётся 2.4.0; browser/session, ЕСИА, credentials и API не меняются.
Миграции, новые scopes и настройки окружения не требуются.

## Что проверить после деплоя

Каталог должен вернуть skill 4.1.6, runtime 1.0.11 и новый package digest.
Безопасный `guides` должен выдать все четыре обязательные части с точными hashes;
раздел проверки статуса во второй части должен содержать новый порядок.
Синтетические сценарии находятся в `../tests/status-check-scenarios.md`.

## Rollback

При подтверждённой проблеме использовать штатный rollback current release на
предыдущую подписанную публикацию. Immutable tag и package bytes не менять.
