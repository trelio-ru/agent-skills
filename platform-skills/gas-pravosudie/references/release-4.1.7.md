# 4.1.7

## Что вошло в релиз

Для обращений и запросов по делу агент проверяет официальный порядок подачи
и предлагает подходящий раздел ГАС «Правосудие» вместо email суда. Доставка
письма не считается регистрацией обращения.

## Миграции и env

Runtime 1.0.12 получает новую immutable version для изменённой инструкции.
Minimum host остаётся 2.4.0; browser/session, ЕСИА, credentials и API не меняются.
Миграции, новые scopes и настройки окружения не требуются.

## Что проверить после деплоя

Каталог должен вернуть skill 4.1.7, runtime 1.0.12 и новый package digest.
Безопасный `guides` должен выдать все четыре обязательные части с точными hashes;
раздел проверки статуса во второй части должен содержать правило выбора канала.
Синтетические сценарии находятся в `../tests/status-check-scenarios.md`.

## Rollback

При подтверждённой проблеме использовать штатный rollback current release на
предыдущую подписанную публикацию. Immutable tag и package bytes не менять.
