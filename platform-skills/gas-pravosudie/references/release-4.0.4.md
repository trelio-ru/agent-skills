# 4.0.4

Runtime 1.0.4; minimum host сохранён без изменения.

Исправлена регрессия входа: публичная страница ГАС возвращает стандартную
форму авторизации с HTTP 401. Runtime допускает её только до ЕСИА после полной
проверки известного соглашения и единственной кнопки входа. Проверка повторяется
перед согласием и созданием helper-а; смена страницы не переносит исключение.

401 без стандартной формы, изменённое согласие, другой origin, остальные HTTP
ошибки и 401 рабочего документа или callback остаются ошибками. Исключение
не подтверждает вход, не повторяет попытку и не меняет хранилище или lease.

Регрессии проверяют прямую форму и переход по ссылке «Вход», изменённые формы,
403/429/5xx, чужие origins, смену страницы во время проверки и strict callback.

На Windows исправлен первый запуск native helper при стандартной политике
Restricted: проверенный bootstrap получает разрешение только для своего процесса.
Постоянные политики ОС и проверки owner/DACL не меняются. Релиз проверяется
реальным DPAPI roundtrip на Windows, без credentials и CredUI.
