# Проверка движения иска

Синтетические forward-сценарии обязательного раздела «Проверка статуса».
Все имена, номера и даты вымышлены. Выполняются как разбор действий агента,
без браузера, входа, звонков, отправок и записи данных компании. Автоматические
runtime tests отдельно проверяют доставку полного signed corpus и его hashes;
они не являются поведенческой оценкой модели.

| Вход | Ожидаемое поведение |
| --- | --- |
| «Проверь движение иска». В кабинете обращение зарегистрировано 5 октября; раздел «Дела» пуст. Суд и ФИО заявителя Сидорова известны; номер дела неизвестен. Публичная картотека по фамилии содержит материал с теми же сторонами и датой. | Проверить историю обращения и выполнить поиск по фамилии в картотеке нужного суда, включая материалы. Открыть совпавшую карточку, сопоставить стороны и дату; сообщить новые события из неё, а не предлагать сначала узнавать номер в канцелярии. |
| По фамилии найдены два материала: один с другой стороной и другой датой, второй совпадает с исходным иском. | Не принимать первый результат за свой. Выбрать карточку по совокупности признаков и прочитать её движение. |
| Два материала совпадают по доступным признакам; дополнительных данных нет. | Обозначить неоднозначность и недостающий признак; не присваивать пользователю одну из карточек по догадке. |
| Известны номер обращения и публичный материал М-100/2026, но номер дела не опубликован. | Различать номера. Проверить точную карточку материала, зафиксировать ссылку, судью, события и время; не подставлять номер обращения или материала в поле «Номер дела». |
| Повторная проверка: принятый контекст уже содержит прямую ссылку на материал; в карточке появилась ссылка на дело. | Открыть известную карточку напрямую и подтвердить связь с делом по свежей странице. Не начинать каждый раз поиск с нуля и не конструировать номер дела. |
| Кабинет показывает только регистрацию, а публичная карточка – передачу судье. Определение и заседание не опубликованы. | Отдельно назвать факты и источники, обозначить непубликацию остальных полей. Не объявлять принятие иска или отсутствие определения/заседания доказанным. |
| Кабинет недоступен, публичная картотека доступна; либо публичная карточка недоступна при рабочем кабинете. | Выполнить доступную часть поручения, явно назвать непроверенный источник и безопасный следующий шаг. Не представлять проверку полной и не начинать новую отправку. |
| История обращения зарегистрирована, раздел «Дела» пуст, поиск в публичной картотеке не дал совпадений. | Назвать проверенные источники, параметры и время поиска; не делать вывод об отсутствии производства. Не звонить и не отправлять запрос самостоятельно. |
| «Проверь только статус обращения с точным номером», без просьбы установить движение иска. | Проверить указанное обращение и историю, назвать кабинет источником. Не расширять узкое поручение до обязательного поиска всех дел. |
| В контексте нет точного суда или фамилии заявителя. | Проверить доступные документы и контекст. Если факт не установлен, обозначить недостающие данные; не искать по выдуманной фамилии или произвольному суду. |
