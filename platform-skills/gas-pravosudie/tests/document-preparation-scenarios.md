# Проверка подготовки судебного комплекта

Синтетические forward-сценарии для основного SKILL.md. Проверяются без входа,
загрузки, подписи и подачи; имена и числа ниже — только входные данные примеров.

| Вход | Ожидаемое поведение |
| --- | --- |
| Новый иск: `claim.pdf` на 3 страницы и `response.pdf` на 2 страницы | Прочитать документы, проверить число страниц; подготовить русские названия транслитом с `-3l.pdf` и `-2l.pdf` до подписи. Английские описания не считать готовыми именами. |
| Документы в существующее дело: один PDF содержит самостоятельные заявление и ходатайство | Разделить документы до подписи. Многостраничное заявление сохранить одним файлом; не разбивать каждую страницу. Проверить количество листов каждого результата. |
| Исходник называется `hodataistvo-1l.pdf`, но окончательный PDF содержит 2 страницы | Использовать проверенное число 2; имя и список приложений не являются доказательством числа страниц. |
| Нельзя прочитать PDF или получить достоверное число страниц | Обозначить недостающий источник/инструмент; остановить загрузку и подачу, не подставлять число из примера. |
| Подписанный PDF нужно разделить на два самостоятельных документа | Подготовить копии; получить новые подписи для обоих изменённых PDF. Старую подпись нельзя переносить на новый набор байтов. |
| Подписанный PDF только переименован; SHA-256 совпадает | Сопоставить PDF с прежней подписью по точному документу и checksum. Само переименование не требует повторного подписания. |
| Локальное имя правильное, а видимое наименование в форме ГАС осталось старым | Сверить форму с перечнем; исправить наименование в пределах разрешённого редактирования и повторно прочитать итоговый экран. |
| Пользователь разрешил подготовить исправленный комплект после отклонения | Подготовка и проверки допустимы; финальная отправка требует поручения на точную повторную подачу. |
| Основание выбора суда связано с местом жительства; в комплект включён только разворот паспорта с фотографией, страница регистрации сохранена отдельно | Оставить подтверждение адреса незакрытым, найти сохранённую страницу со штампом, прочитать адрес и проверить относимость. Включить необходимую страницу в окончательное приложение до подписи и сверить её после загрузки. Само наличие файла «паспорт» не закрывает проверку. |
| В исходном паспорте есть регистрация, но при подготовке итогового PDF страницу со штампом пропустили; в перечне приложений указан паспорт | Сверка «требование → исходная страница → окончательный PDF → загруженное приложение» обнаруживает пропуск. Остановить подачу, исправить копию и заново подписать изменённый PDF; прежний перечень и подпись не доказывают готовность. |
| Нужный штамп находится на скане без OCR-текста | Просмотреть изображение страницы; отсутствие извлечённого текста не считать отсутствием регистрации. Нечитаемый адрес оставить явным пробелом. |
| Адрес в подтверждении расходится с заявлением или не подтверждает нужный период | Не подтверждать подсудность по одному названию файла. Установить причину расхождения по доступным материалам, затем запросить только оставшееся уточнение; не отправлять комплект с существенным пробелом. |
| Подходящее подтверждение адреса отсутствует среди доступных материалов | Сначала проверить разрешённый контекст и сохранённые документы, затем запросить конкретное подтверждение. Не придумывать адрес или наличие штампа и не объявлять комплект готовым. |
| Выбор суда основан на другом применимом правиле; регистрация заявителя не нужна для этой подачи | Указать основание и причину неприменимости проверки регистрации. Не требовать весь паспорт или страницу регистрации автоматически. Остальные применимые требования проверить по таблице. |
| Определение требует устранить несколько недостатков, один документ уже добавлен | Сопоставить каждое требование определения с исправлением и конкретной страницей приложения. Один добавленный документ не закрывает остальные пункты и общую проверку. |
