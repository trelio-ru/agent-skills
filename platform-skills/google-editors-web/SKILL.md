# Google Таблицы и Документы

Работай только через подписанный браузерный рантайм этого навыка. Вход проходит человек в видимом Chromium. После сохранения личной сессии выполнение идёт в headless Chromium. Отдельные браузеры, API Google, приватные HTTP endpoints и импорт других сессий не подставляются.

Перед первой рабочей командой вызови `guides` и полностью прочитай все части в возвращённом порядке. Сверь каждый путь, размер и SHA-256 с ответом. Если часть недоступна, обрезана или не совпала, останови работу. Точный перечень команд возвращает `commands`.

Прежде чем менять данные, сверь выбранный человеком аккаунт, файл, лист или вкладку и точный объём поручения. Готовая команда предпочтительна. При подтверждённой остановке до записи можно продолжить по текущим labels/PNG в той же сессии. После возможной записи сначала перечитай фактическое состояние и сохрани неизвестный исход при недостатке доказательств. После работы закрой только сессию навыка.
