# Браузерная проверка Google Таблиц и Документов

18 ноября 2026 года сценарии прогнали на macOS с исходным Chromium host на
базе 3.34.4. Использовали выделенный защищённый профиль и два тестовых файла.
Пользователь вошёл в видимом окне, закрыл его и больше не вводил данные входа.
Рабочий профиль восстановился в Chromium с `--headless=new`. Команды и
управление по свежим кадрам использовали один браузерный сеанс.

- **Sheets.** `read-sheet-range` вернул обе записанные ячейки из `A1:A2`.
  Первоначальная выгрузка CSV получила 307 на файловый CDN Google. Общий
  host теперь разрешает этот redirect только для явного скачивания и
  сохраняет редактор открытым. Подтверждены пустая выгрузка с нового листа,
  переключение листа с проверкой gid и добавление одного листа. После
  ввода формулы через строку формул `read-sheet-formulas` вернул точную
  формулу из XLSX, `read-sheet-range` вернул вычисленное значение из CSV.
- **Docs.** В ранней проверке одно изменение сохранилось, но чтение сразу
  после перехода потеряло подтверждение. Повторное чтение отдельно
  подтвердило сохранённый текст. Обновлённая команда на новой правке
  завершилась `outcome=verified`: полный ожидаемый TXT совпал со свежей
  выгрузкой без перезагрузки редактора при автосохранении.
  `copy-document` создал собственную копию с независимой ссылкой в «Мой диск».
  Перед кликом были подтверждены имя, папка, выключенные флажки переноса
  доступа и комментариев.
- **Экспорт.** Через штатные меню получены проверенные CSV, XLSX, TXT, DOCX
  и PDF. Из DOCX без заголовков получена пустая структура, синтетический
  тест проверяет нумерацию и текст стилевых заголовков.
- **Импорт.** Native chooser принадлежит прямому same-origin frame `/picker`.
  Исходный host отказал с `upload_control_required`. После узкого допуска
  CSV загружен через тот же headless Chromium. Режим «Добавить на текущий лист»,
  запятая и отключённое преобразование выбраны по свежим кадрам. Повторное
  чтение диапазона подтвердило четыре ожидаемые ячейки на выбранном листе.

Проверки исходного пакета не охватывают другие ОС, Google Workspace с
ограниченным доступом, правку многоуровневых вкладок, массовую запись,
форматирование, копирование таблиц и комментарии. Импорт проверен для CSV
с визуальным выбором параметров. Для обычного пакета нужен выпущенный host
с additive API и отдельный прогон
подписанного пакета. Диагностические снимки, сессии и результаты выгрузок
в репозиторий не входят.
