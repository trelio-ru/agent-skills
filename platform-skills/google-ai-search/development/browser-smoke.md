# Google: поиск и ИИ — браузерная проверка

Проверено 4 ноября 2026 года через существующий browser tool Codex, в собственных
скрытых IAB-вкладках. Отдельные browser/runtime/API не использовались. Account,
history, внутренние ссылки AI-беседы и tracking/session-параметры в отчёт не входят.

## Изменение и границы выпуска

Source baseline: `abdf5db` в `trelio-ru/agent-skills`; опубликованная инструкция
Google до изменения — `1.0.0`. Это instruction-only навык без runtime manifest,
package и прежнего provider tag. Candidate — exact commit/PR с этим отчётом,
зафиксированный hosted gate и publication summary. Мажорная версия `2.0.0`
добавляет самостоятельную обычную выдачу и выбор режима; ID `google-ai-search`
сохраняется. Название карточки — «Google: поиск и ИИ».

Меняются инструкция, карточка, Codex prompt и provider-owned controller tests.
Права, personal data disclosure, browser transport, unknown-outcome/no-replay
и host ABI сохраняются. Runtime/backend/plugin deployment не требуется.
План проверок: actual delivered controller, shared instruction/metadata/byte
contracts, hosted source gate и public-source audit, затем current version/CAS,
точные инструкции/routingSummary и отсутствие runtime в каталоге. Межкомпонентный
cold/fault stand не добавляется: executable/session/ACL границы не меняются.

## Реальный сценарий

1. Обычная выдача открыта прямым Google Search URL с самостоятельным запросом
   `site:support.google.com/websearch AI Overviews Web`. Проверены принятый запрос,
   новый список результатов и ссылка на официальную справку.
2. Уточнение через документированный DOM `fill` и Enter заменило запрос на
   `site:support.google.com/websearch/answer/14901683 Web filter`. Прочитана новая
   выдача; исходный запрос и старый результат не приняты за новое выполнение.
3. В наблюдённом меню «Ещё фильтры» выбран «Веб-версия». UI подтвердил выбранный
   фильтр и текстовые ссылки. Параметры фильтра не угадывались и не закреплялись.
4. Открыта реальная ссылка `https://support.google.com/websearch/answer/14901683`.
   Раздел «Как убрать из результатов Google Поиска все, кроме ссылок» подтверждает
   фильтр; snippet и AI Overview не заменили чтение страницы. Вспомогательная
   вкладка закрыта.
5. В отдельной скрытой вкладке `g.ai` после redirect проверены интерфейс AI Mode
   и поле «Задайте вопрос». Отправлен один публичный вопрос о различии обычной
   выдачи и AI Mode с просьбой дать официальную справку. Прочитан полный новый
   ответ с таблицей и ссылкой на `support.google.com/websearch/answer/16011537`;
   завершение подтверждено новым ответом и «Ответ от режима ИИ готов».
6. В той же беседе отправлен вопрос об исключении ИИ-обзоров из обычной выдачи.
   Новый вопрос и завершённый результат относятся ко второму ходу. На этот раз
   AI Mode вернул список ссылок без сгенерированного объяснения. Этот допустимый
   вариант явно различается в инструкции и не выдаётся за связный ответ ИИ.
7. Реальная официальная ссылка первого AI-ответа открыта отдельно и прочитана:
   справка подтверждает составной поиск и уточнения. Вспомогательная вкладка закрыта.
8. С тем же controller выполнен возврат в сохранённую обычную поисковую вкладку:
   `site:support.google.com/websearch/answer/16011537 AI Mode follow up questions`.
   Новый самостоятельный запрос и результат официальной справки проверены.

Общий completion-based controller обслуживал запросы, смену фильтра и AI Mode;
время чтения/размышлений засчитывалось в интервал 2–15 секунд. Тесты исполняют
snippet прямо из SKILL.md и проверяют общий clock и unknown-send fence обоих режимов.

Предварительная проверка показала, что Google search combobox не имеет native
AX settable value: `setValue` был отклонён до ввода/Enter. Исходный запрос
остался неизменным, отправки не было. После завершения этого preflight полный
сценарий выполнен через документированный DOM fill, без повторной неизвестной
отправки. AI textbox имеет settable value; там native ввод/Enter сработали.

## Ограничения

Проверен текущий русский интерфейс в доступной browser-сессии. CAPTCHA, ручной
вход, другие регионы и аккаунты не имитировались, настройки не менялись.
Проверка не обещает одинаковую выдачу, наличие AI Mode или отсутствие CAPTCHA
у всех пользователей. Источники и ответы проверяются заново при каждом исследовании.
