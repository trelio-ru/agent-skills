# Госуслуги 4.3.8

На QR-экране ЕСИА перечисление альтернативного входа может содержать слова,
которые общий классификатор воспринимает как ручную проверку. Runtime 3.3.8
сначала связывает экран с единственной видимой кнопкой «Логин и пароль»,
проверяет отсутствие отдельных препятствий и выбирает её один раз. Если
переход не подтверждён, повторного клика по той же странице нет.

Синтетический сценарий теперь включает альтернативный способ «Биометрия»
ниже кнопки пароля и проверяет вход до callback. Отдельные CAPTCHA, SMS/push,
согласие и выбор роли по-прежнему требуют участия пользователя.
