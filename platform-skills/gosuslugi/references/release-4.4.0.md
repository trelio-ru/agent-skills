# Госуслуги 4.4.0

Вход через промежуточное окно больше не должен оставлять пошаговый сценарий
в бесконечном ожидании. `observeEsiaAuthorization` показывает состояние
запроса, проверенный возврат ЕСИА и безопасную ошибку, сохраняя доступность
команд браузера между первым и вторым login click.

Пример долгоживущего caller возвращает управление сразу после клика и получает
request/authenticated отдельными событиями. Если запрос не появился за 15
секунд, агент проверяет промежуточную публичную страницу в той же попытке.
Это диагностический срок, который не отменяет и не продлевает native lease.
Настоящий challenge и право на отправку оцениваются отдельно по фактам.

Синтетическая проверка воспроизводит форму с текстом/файлом, modal, второй
click, direct popup и возврат в исходный context. Unit tests проверяют
доступность очереди, поздний request, terminal failure и безопасный вывод.

Skill 4.4.0, runtime 3.4.0, minimum host 3.0.22. Callback/state, запрет replay,
native permit, encrypted vault и границы подачи сохраняются.
