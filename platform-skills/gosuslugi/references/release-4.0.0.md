# Госуслуги 4.0.0

## Что вошло в релиз

Runtime 3.0.0 предоставляет клиент ЕСИА для обычного Playwright-сценария.
Агент создаёт headed browser, подключает помощник перед штатным входом и
после проверенного callback продолжает с теми же `context` и `page`.
Доступны произвольный код, формы, upload/download и переходы между сайтами.
Отдельный навык secure-browser удалён; сайты и их процедуры не входят в Госуслуги.

Сохранённые доступы остаются в прежнем encrypted vault. Seed и OS key не
передаются клиенту. Login/password/current TOTP вводятся через приватный канал
в доверенном процессе сценария. Полный Playwright context имеет технический
доступ к auth DOM, cookies и сети; изоляция от кода сценария не обещается.
Native deadline ограничивает доступ помощника к credentials; браузер закрывает
создавший его сценарий. Быстрый SSO callback обходится без чтения vault.

## Миграции и env

Новые env и DB migration не нужны. Minimum host – 1.6.17. Сохранённые credentials
и native key namespace не меняются; повторный setup не нужен. Старые активные
сессии завершаются перед обновлением. Прежний delegated browser API заменяется
командой `client` и примером из возвращённого `guidePath`; собственный портал
Госуслуг сохраняет прежние команды и lifecycle.

## Что проверить после деплоя

Свежий каталог возвращает 4.0.0/runtime 3.0.0 и exact новый digest. Verified
`client` указывает на модуль и руководство внутри этого пакета. Проверить
разрешённый вход ЕСИА, возврат в исходную вкладку, рабочую страницу кабинета
и закрытие созданного браузера. Callback не доказывает подачу документов.
ГАС получает новую инструкцию без зависимости от secure-browser.

Regression gate проверяет native deadline/ACL, auth/storage/roles, два headed
синтетических входа с password/TOTP и быстрый SSO, identity context/page,
произвольный код, форму, upload, browser Blob download, cookies и переходы.
Blob-проверка не доказывает скачивание HTTP-вложения реального провайдера.
Реальный разрешённый smoke проводится отдельно от синтетических тестов.

## Rollback

Остановить авторизацию и вызывающий сценарий, сохранив encrypted vault.
Отключить новый flow и выпустить исправленный immutable runtime с новой
identity. Возврат исторического package допускается только с проверкой его
зависимостей; удалённый браузерный навык автоматически не восстанавливается.
Tags и опубликованные package bytes не переписываются.
