# Госуслуги 4.5.7

Если пользователь уже разрешил вход через Госуслуги на конкретный сайт, runtime
сам проходит стандартное согласие ЕСИА на просмотр данных профиля. Повторный
вопрос и ручное нажатие «Выдать разрешение» больше не требуются.

Полный экран, read-only права, native permit и связанная transaction проверяются
повторно перед единственным кликом. Неизвестные права, другие согласия, подача,
платёж и подпись сохраняют отдельные основания. Generic click не расширяется.

Runtime 3.5.7, minimum host 3.7.1. Синтетические регрессии проверяют автоматическое
согласие в same-page и popup flow, изменения экрана, callback до dispatch и
отсутствие повторного клика при задержке/неизвестном результате. Они не доказывают
вход на реальный аккаунт или совместимость конкретного внешнего кабинета.
