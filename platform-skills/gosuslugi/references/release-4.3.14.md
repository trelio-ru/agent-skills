# Госуслуги 4.3.14

Результат входа во внешний сервис теперь привязан к конкретной попытке.
Потерянная или неуспешная авторизация больше не становится успешной из-за
готовности отдельной сессии Госуслуг. Безопасная диагностика сохраняет причину,
этап запуска и наблюдённый HTTP-код, не раскрывая данные входа.

Блокировка аккаунта и отказ в данных останавливают автоматический ввод,
включая новые процессы и запросы. Запрет хранится в прежнем encrypted vault;
перезапуск и обновление его не сбрасывают. После сообщения пользователя о
снятии блокировки можно явно продолжить вход без повторения уже отправленных
пароля/кода. Открытые страницы и черновики вызывающего браузера сохраняются.

Runtime 3.3.14; minimum host 3.0.22. Новый host/plugin и product release не нужны.
Проверки используют только синтетические данные, реальный headed браузер и
native guardian на macOS/Windows; они не доказывают настоящий provider login.
