# Госуслуги 4.3.16

Закрытый статус после обычного завершения использует ту же безопасную projection,
что и после выхода guardian. Старые receipts получают текущую ссылку на форму
восстановления; бывший live phase, неизвестные поля и посторонние ссылки не
переносятся в результат. Частичный cleanup не вызывает прежний control port.

Отказ обычного OAuth callback указывает конкретную проверку: target, method,
fragment, state или fixed query. Все исходные условия остаются обязательными;
URL и значения авторизации не выводятся. Это диагностика, а не подтверждение
входа или разрешение автоматического повтора.

Skill 4.3.16, runtime 3.3.16, minimum host 3.0.22.
