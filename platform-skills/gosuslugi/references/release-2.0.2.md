# Госуслуги 2.0.2

## Что вошло в релиз

Исправлена загрузка страницы личного кабинета: прежний фильтр блокировал CSS,
AngularJS, шрифты и HTML-шаблоны с `gu-st.ru`, оставляя пустое оформление и
выражения `{{…}}`. Новый фильтр разрешает статические ресурсы exact CDN,
отдельно ограничивает пути XHR/fetch для шаблонов и переводов и сохраняет
запрет CDN-навигации, POST, произвольных API и хранения чужих origins.

Браузерная регрессия теперь проходит через настоящий `Portal.open`, включая
production request policy. Synthetic transport подставляется только после
проверки запроса; прежний тест обходил эту часть runtime.

Пакет также включает подготовленное в main уточнение macOS-диагностики:
`doctor` проверяет доступность login Keychain без чтения значений и без UI,
отличает её отказ от отмены Touch ID и блокирует бесполезный повтор входа.
Native helper в системном окне называется `Trelio`.

## Миграции и env

Runtime 1.0.1; minimum host остаётся 1.6.17. Namespace и формат зашифрованного
vault не меняются, новый ввод credentials не требуется. Активная сессия старого
runtime заканчивается штатным `stop`; следующая использует новый package.
Изменений Trelio, plugin, connection settings или env нет.

## Что проверить после деплоя

Свежий каталог должен вернуть 2.0.2/runtime 1.0.1 и новый package digest.
Безопасный `doctor` выполняется только через exact action этого релиза.

Публичная maintainer-проверка без личной сессии:

```bash
node platform-skills/gosuslugi/development/run-public-bootstrap.mjs
```

На macOS исходный фильтр воспроизвёл восемь необработанных шаблонов и отказы
CSS/AngularJS с CDN. После исправления шаблонов нет, оформление, HTML и
переводы загружаются с HTTP 200, на странице доступен вход. Это проверка
публичного bootstrap, а не доказательство входа в реальный аккаунт ЕСИА.
Native/browser regressions на Windows и macOS выполняет отдельный security
workflow; настоящий вход с OS unlock и ручными проверками требует пользователя.

## Rollback

Через guarded rollback выбрать прежний неотозванный release с проверкой exact
current release. Опубликованные tags и runtime packages не изменять. Старый
runtime сохранит прежний дефект загрузки CDN, поэтому откат возвращает этот сбой.
