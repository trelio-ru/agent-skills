# Госуслуги 4.4.2

Runtime 3.4.2 показывает название запрашивающего Codex-чата и при ограниченном
PATH подписанного host. Перед exact metadata read runtime разрешает CLI в
абсолютный исполняемый файл, включая фиксированные bundle locations ChatGPT
и Codex на macOS. Поиск не расширяет PATH и входит в общий трёхсекундный срок.

Cross-platform regression проходит discovery и настоящий subprocess protocol
с ограниченным окружением, проверяет exact thread ID и передачу выбранного
названия в native stdin. Native helpers и их Keychain identity не меняются.
Minimum host остаётся 3.0.22; при недоступном CLI сохраняется прежний fallback.
