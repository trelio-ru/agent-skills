# Госуслуги 4.5.8

## Что вошло в релиз

Исправлен пример долгоживущего Playwright caller. Ошибки команд, locator и
скачивания сохраняются отдельно от результата ЕСИА и не превращают проверенный
callback в `authorization_result_unknown`. Очередь продолжает принимать
`state` и `finish`.

Пример скачивания сразу наблюдает оба promise, ждёт завершения click и `saveAs`.
Locator проверяется по фактической роли или уникальному тексту. Cleanup по
`finish` и EOF пытается закрыть все собственные ресурсы даже при ошибке одного
`close()`; чужой браузер не закрывается.

## Миграции и env

Skill 4.5.8, runtime 3.5.8, minimum host 3.7.1. Новых migrations, env, OAuth
scopes и требований к host нет. Сохранённые аккаунты и credentials не меняются.
Новая runtime version обеспечивает доставку исправленных документов в отдельном
неизменяемом подписанном package.

## Что проверить после деплоя

Свежий `get_agent_skill` в назначенном scope должен вернуть 4.5.8 / 3.5.8 и
minimum host 3.7.1. Проверить exact package digest и доставленный Playwright guide
через безопасный `guides`, без нового входа, заявки или подписи.

Синтетические тесты проверяют ранний timeout download при продолжающемся click,
ошибку `saveAs`, сохранение callback, восстановление очереди и cleanup. Headed
smoke проверяет `a role="button"` и сохранение настоящего download stream на
macOS/Windows; он не доказывает совместимость живого Госключа или реальный вход.

## Rollback

При подтверждённой регрессии использовать штатный возврат current release на
предыдущую опубликованную 4.5.7. Не изменять tags и package bytes; при следующем
исправлении выпустить новые skill/runtime versions.
