# 4.3.12

Runtime 3.3.12; minimum host сохранён без изменения.

Исправлена потеря HTTP-кода при ошибке портала: ответ 503 теперь передаётся как
service_http_error с httpStatus=503 и origin сервиса. Данные входа, OAuth URL,
сетевые тела и auth DOM не раскрываются. Недоступность сервиса не вызывает
повторный setup или автоматическое повторение входа/отправки.

Проверки покрывают ошибки до ЕСИА, на ЕСИА и на callback, сохранение кода между
процессами и запрет небезопасных metadata. Настоящий аккаунт для регрессий не нужен.
