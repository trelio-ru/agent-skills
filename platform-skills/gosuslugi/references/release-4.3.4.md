# Госуслуги 4.3.4

## Название чата в системном окне

Runtime 3.3.4 по `CODEX_THREAD_ID` читает название текущего чата из локального
Codex App Server и сверяет ID ответа. Проверенный заголовок используется для
системного подтверждения доступа к хранилищу. Переданная агентом короткая тема
не переопределяет результат чтения. Если Codex не вернул точный заголовок, тема
из прежнего optional `requestTitle` служит fallback; без неё окно показывает
нейтральный текст. В Claude Code используется переданная агентом тема.

Заголовок не сохраняется в vault или lease. Native macOS/Windows helper и его
trusted-app identity не меняются. Синтетические тесты проверяют exact ID,
приоритет локального чтения и нейтральный fallback; локальное чтение текущего
чата проверено через Codex App Server.
