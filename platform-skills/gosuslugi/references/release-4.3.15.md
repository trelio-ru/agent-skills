# Госуслуги 4.3.15

При ограничении доступа навык сообщает конкретный следующий шаг: самостоятельно
пройти проверку в официальной форме https://www.gosuslugi.ru/679557/1/form.
Ссылка и пояснение доступны также после завершения попытки авторизации.

Сообщение учитывает, что ограничение входа во внешние сервисы может действовать
при доступном портале Госуслуг. Проверка остаётся у пользователя; новый вход
не запускается автоматически и требует сообщения о снятии ограничения.

Runtime 3.3.15; minimum host 3.0.22. Обновление host/plugin и product release
не нужны. Проверки синтетические и не доказывают снятие ограничения аккаунта.
