# Госуслуги 4.0.1

## Что вошло в релиз

Runtime 3.0.1 завершает передачу полного Playwright context только после
проверенного callback и фактического document commit. Начало callback сразу
прекращает дальнейший ввод данных входа. Промежуток между ответом сервера и
переходом страницы больше не вызывает преждевременный `complete` или повторное
чтение auth-формы. Тот же порядок действует при обычном входе и быстром SSO.

## Миграции и env

Env, DB migration и повторный setup не нужны. Сохранённые доступы остаются
в прежнем vault. Minimum host – 1.6.17. Полный Playwright API и отсутствие
зависимости от secure-browser соответствуют контракту 4.0.0.

## Что проверить после деплоя

Свежий каталог возвращает 4.0.1/runtime 3.0.1 и exact digest. Проверить signed
`client`, исходные context/page и завершение разрешённого ЕСИА-входа без
повторного credential submit. CI проверяет задержанный document commit,
callback между state/observe, headed password/TOTP/SSO на macOS и Windows.

## Rollback

Остановить затронутую авторизацию и выпустить исправленный immutable runtime
с новой identity. Не восстанавливать автоматически удалённый secure-browser,
не переписывать tags и не удалять encrypted vault. Callback сам по себе не
подтверждает вход в кабинет или подачу документов.
