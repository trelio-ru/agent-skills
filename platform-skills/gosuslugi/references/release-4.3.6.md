# Госуслуги 4.3.6

Runtime 3.3.6 сохраняет автоматическое продолжение входа ЕСИА после ручной
проверки. Минимальная версия подписанного host снижена до уже опубликованной
`3.0.22`: чтение точного названия чата по `CODEX_THREAD_ID` необязательно и при
отсутствии этой переменной использует прежний безопасный fallback.

После публикации 4.3.5 защищённый `doctor` выявил
`AGENT_SKILL_RUNTIME_HOST_UPGRADE_REQUIRED` на host `3.0.22`, поэтому только
каталожный read-back не считался рабочей проверкой. Для этого релиза обязательны
тот же cross-platform regression и защищённый `doctor` уже опубликованного пакета.
