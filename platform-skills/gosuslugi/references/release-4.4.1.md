# Госуслуги 4.4.1

Подготовленную форму можно продолжить через защищённый вход, сохранив вкладку,
текст, выбранные файлы и уже принятое пользователем согласие.

- Пошаговый пример различает завершённый helper и новую разрешённую процедуру.
  Пожизненный запрет второго helper больше не приводит к ручному входу.
- Для ПОС сначала готовится точная форма; отдельный вход на главной не требуется.
- Pending, отказ и неизвестная отправка по-прежнему запрещают повтор.
- Runtime 3.4.1; minimum host остаётся 3.0.22. Хранение, OS unlock,
  state/callback checks и независимые полномочия на подачу сохраняются.
