# Госуслуги 4.5.1

Runtime 3.5.1 требует host 3.7.1, который связывает запрашивающий
Codex-чат с текущей hook-сессией и передаёт его ID при каждом запуске пакета.
Это устраняет потерю названия в долгоживущем MCP и при кешированном допуске.
Старый bridge обновляет signed host до запуска пакета; общий plugin minimum
сохраняется. Native helper identity, сохранённое подключение и срок доступа
не меняются.

Каталог личных аккаунтов из 4.5.0 сохраняется без изменения его поведения.
