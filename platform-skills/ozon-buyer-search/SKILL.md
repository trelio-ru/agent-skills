# Ozon для покупателя

## Основное правило

Используй только покупательский Ozon: поиск, карточки, отзывы, delivery, собственные покупки и заказы. Не открывай Ozon Seller, рекламу, seller orders, цены или остатки продавца.

Работай в отдельной agent-owned вкладке уже авторизованного локального браузера. Не читай cookies, local storage, tokens, saved passwords и файлы профиля. Не захватывай и не меняй существующие пользовательские вкладки. CAPTCHA и anti-bot проходит пользователь вручную; не обходи их и не переходи к угаданным данным.

## Браузер и фокус

Если пользователь явно выбрал браузер, используй его. Иначе предпочитай встроенный Browser с поддержкой скрытой работы: в Codex это `iab`, а при доступном `cua.createBrowserTab` вкладка создаётся с `{ visible: false }`. Обычный поиск, переходы по карточкам, чтение отзывов и проверка доставки не требуют показывать браузер пользователю.

Проверь сессию по обычной странице Ozon. Встроенный Browser имеет отдельный профиль: наличие входа в Chrome не доказывает вход в Browser. Если для задачи нужен личный доступ, а его здесь нет, предложи один ручной вход в Browser либо использование уже авторизованного Chrome. Не переноси cookies или профиль между браузерами и не утверждай, что скрытый режим обходит CAPTCHA.

Для управления видимостью используй только API, объявленный текущим browser tool: например, capability `visibility`, если он доступен. Покажи текущую вкладку только по просьбе пользователя или для login, CAPTCHA и другого обязательного ручного шага. После handoff верни её в скрытый режим, если пользователь не просил оставить браузер видимым; вкладку и сессию при этом сохраняй.

Если скрытый Browser недоступен или пользователь выбрал Chrome, используй одну вкладку и минимизируй переключения: читай состояние страницы через browser API и переходи по проверенным ссылкам без лишних экранных кликов. Не активируй окно специально для каждого чтения и не создавай вкладку для каждого товара. У Chrome-инструмента может не быть управления видимостью; в таком случае не обещай полностью устранить перехват фокуса и не имитируй его устранение повторным переключением приложений.

## Сессия

1. Создай одну отдельную вкладку/группу для текущей задачи и выполняй поиск последовательно в ней.
2. Если нужен login, CAPTCHA или ручная проверка, оставь только эту вкладку для handoff и продолжи после пользователя.
3. После завершения закрой только agent-owned вкладку. Не трогай остальные вкладки пользователя.

## Поиск и сравнение

1. Уточни только ограничения, влияющие на результат: назначение, бюджет, модель/размер, количество, исключения брендов, адрес и срок доставки.
2. Просмотри примерно 12–24 полезных результата, затем открой финалистов по одному.
3. Сверь точную модель, комплект, цену, рейтинг, число отзывов, продавца, availability и delivery. Для рискованного товара прочитай повторяющиеся жалобы в отрицательных отзывах.
4. На каждом финалисте сделай один bounded pass по `Есть дешевле`, вариантам продавца и ближайшим эквивалентам. Замени рекомендацию, если найден действительно тот же товар без худших существенных условий.
5. Верни компактное сравнение с прямыми canonical Ozon links и отдели видимые факты от собственного вывода.

## Доставка по адресу

1. Используй адрес, прямо названный пользователем; если сохранённых вариантов несколько и они меняют результат, уточни выбор.
2. Выбор уже сохранённого exact address для проверки delivery входит в просьбу пользователя. Создание, редактирование и удаление адреса требует отдельной команды.
3. Минимизируй данные адреса: достаточно короткой метки, без получателя, телефона, подъезда и инструкций.
4. Фильтр `Завтра` – только discovery hint. Проверь точную дату и способ на странице каждого финалиста и повторно сверь selected destination.

## Собственные заказы и купленные товары

1. Exact order-details URL разрешает открыть и прочитать этот заказ, но не менять его.
2. Читай только нужные поля: номер, status, items, quantities, totals, seller, order/delivery dates, method и наличие receipt. Полный адрес, телефон, получателя и payment instrument не копируй без необходимости.
3. Для старого товара ищи в `Купленные товары`. Если карточка закончилась, открой его own image/panel и canonical archived product page; last shown price не выдавай за purchase price.
4. Cancel, return/refund, confirm receipt, reorder, delivery change, seller message, review, receipt download и любая другая mutation выполняются только по явной просьбе о точном действии и с требуемым action-time confirmation.
5. После неоднозначного результата mutation сначала установи live state; не повторяй действие автоматически.

## Совместимость

Навык работает на macOS, Windows и Linux, если Trelio host умеет управлять встроенным Browser либо локальным Chrome/Chromium-подобным браузером с пользовательской сессией. Скрытая работа зависит от возможностей выбранного browser tool. Без local browser control доступны только публичные карточки, но не адресная доставка и собственные заказы; не подменяй их web-search результатами.
