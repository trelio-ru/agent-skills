# Trelio Agent Skills

Публичный репозиторий общих provider Agent Skills Trelio.
Инструкции, runtime-код, тесты и инструменты сборки публикуются отдельно от
корпоративных навыков, личных подключений и production signing.

В `platform-skills/` находятся 20 общих навыков: 1С ЭДО, Авито, ВКонтакте, КонсультантПлюс,
DodoStats / DrinkitStats, Google AI Search, почта, ГАС «Правосудие», Госуслуги,
iPhone Mirroring, Yandex Search,
MAX, поиск Ozon, заказные письма Почты России, Т-Банк, Telegram MTProto,
Telegram Web, WhatsApp, факсимиле для документов и ВК Реклама. Для конкретного provider
читай его `SKILL.md`.

Авито – прототип браузерного навыка: модель получает отрисованный текст и
координаты, PNG по запросу; входящие вложения выдаются локальными originals; отправляет клики, прокрутку, обычный текст и клавиши. Ручной вход сохраняется
локально в защищённой сессии. Нужен host visual API >=3.11.0; source и PR не
означают публичную готовность до native CI и signed host/provider release.

ВКонтакте использует тот же визуальный host API >=3.11.0: поиск, страницы,
сообщества и диалоги по отрисованному тексту и PNG, обязательный вход через VK ID,
защищённый локальный snapshot и отдельный личный account. Разделы VK доступны
по задаче пользователя; scope охватывает HTTPS vk.ru/vk.com с поддоменами и vk.me.
Доступность конкретного действия определяется интерфейсом и командами runtime.
ВК Реклама предоставляет отдельный рекламный API. Входящие originals ограничены signed origin policy;
редирект на внешний CDN может быть недоступен. Source и синтетические тесты не
доказывают текущую совместимость живого VK: до signed release нужен live smoke.

Google AI Search – instruction-only прототип на существующем browser tool:
скрытая вкладка `g.ai`, уточнения в одной беседе, случайный минимальный интервал
2–15 секунд от готового ответа до следующего вопроса и прямые ссылки на источники.
Размышления модели входят в интервал; перед отправкой ожидается только остаток.
Скрытая вкладка не обещает headless process. Наличие исходника не означает
публикацию или назначение навыка в live каталоге Trelio.

Yandex Search использует обычную выдачу `yandex.ru/search/` в скрытой вкладке.
Уточнение становится самостоятельным поисковым запросом с прежней темой;
перехода в Dzen или Алису AI нет. Интервал 2–15 секунд учитывает время
размышлений и чтения источников, перед отправкой ожидается только остаток.

Текущую доступность подписанного навыка ВК Реклама определяет live каталог
Trelio, а не наличие исходников. Для новых функций чтения нужен безопасный
GET smoke; новые записи проверяются только на отдельно разрешённых тестовых
объектах без запуска показов.
`sources --type search-phrases --id ID` читает сами поисковые и минус-фразы;
название сегмента не заменяет источник правил, единица периода и expansion
сохраняются как неизвестные, если официальный API их не определяет.
Управление сегментами/источниками, rename/delete загруженных списков и явная
Top goal привязка используют scoped plan/apply из
[контракта управления](platform-skills/vk-ads/references/audience-management.md).
Новые write-пути проходят синтетические тесты; реальный результат конкретного
кабинета устанавливает его отдельно разрешённая операция с read-back.
Источник подписчиков VK-сообщества отдельно разрешается в рекламном словаре,
регистрируется и читается с состоянием загрузки. Публичный ID и внутренний ID
источника не смешиваются; legacy official contract не доказывает доступность
нового endpoint в конкретном кабинете ads.vk.com.

Корпоративные 1С и устаревший Telegram-пилот сюда не входят. История начинается
с отобранного source snapshot; исторические release tags сохраняют первоначальную
provenance. Текущие опубликованные версии и подключения Trelio не меняются от
переноса исходников. Новый tag не создаётся только ради изменения repository.

`platform-skills/tools/` содержит детерминированный builder и регрессии.
Проверки идут на Linux/macOS/Windows через GitHub Actions. Быстрый локальный gate:

```sh
node --test platform-skills/tools/*.test.mjs
node platform-skills/tools/check-public-source.mjs
```

[Порядок выпуска](docs/release-process.md) сохраняет production signing на
backend. Telegram application identity и сборка содержащего её artifact остаются
в приватном release-контуре. Корпоративные source и старые artifacts сохраняются
приватными. Лицензии сторонних компонентов лежат рядом с их исходниками;
отдельная новая лицензия на весь проект этим переносом не вводится.
